# 三期集成联调说明（报工 · 分批入库 · 金蝶推送）

版本基线：P3（前序基线 P1=4b33a11，P2 已 ACCEPT）

## 1. 金蝶 K3 沙箱/生产配置点（config/k3.php 或 .env）

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `K3_BASE_URL` | `http://127.0.0.1:8002` | 金蝶 WebAPI 地址；沙箱指向本仓库 `scripts/k3-mock-server.php` |
| `K3_MOCK` | `true` | 模拟模式（跳过登录直调 Save）；真实联调置 `false` |
| `K3_ACCT_ID / K3_USERNAME / K3_PASSWORD` | demo | 金蝶账套/账号/密码（登录拿 `kdservice-sessionid` Cookie） |
| `K3_STOCK_ID / K3_BILL_TYPE_ID / K3_CREATOR_ID` | 100080 / SCM000018 / 48 | 默认仓库/生产入库单类型/创建人（按客户账套修改） |

**模拟端点**：`php -S 127.0.0.1:8002 scripts/k3-mock-server.php`
- 成功：`Save` 返回 `{Result:{ResponseStatus:{IsSuccess:true}, Id, Number}}`
- 可配置失败：`K3_MOCK_FAIL=1`（业务失败）/ `K3_MOCK_HTTP_FAIL=1`（HTTP 500）驱动重试
- 报文契约：`FEntity.FMaterialId / FRealQty / FSrcBillNo / FStockId / FDate / FBillTypeId / FCreatorId / FNote`

**真实联调**（客户环境）：置 `K3_MOCK=false` + 真实账套配置 → `POST /api/warehouse/ins/{id}/push` 手动验证，`GET /api/system/integration-logs` 对账。

## 2. 企业微信扫码免密配置点（config/wecom.php 或 .env）

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `WECOM_MOCK_MODE` | `false` | `true` 时 `wecom-login` 的 code 直接匹配 `users.wecom_userid`（沙箱走通流程） |
| `WECOM_CORP_ID / WECOM_SECRET / WECOM_AGENT_ID / WECOM_OAUTH_REDIRECT_URI` | 空 | 真实企微凭证；配好后置 `WECOM_MOCK_MODE=false` |

微信扫码：`WX_APP_ID / WX_APP_SECRET`（一期小程序/公众号配置，扫码拿 openid 调 `wx-login`）。

## 3. 队列与重试

- `QUEUE_CONNECTION`：生产用 `redis`/`database`（`php artisan queue:work`）；测试与演示 `sync`
- 金蝶推送 Job `PushStockInJob`：`tries=5` + 递增退避（5/15/60/180/600s）；失败后 `k3_push_status=failed`，可
  `POST /api/warehouse/ins/{id}/push` 手动重推（幂等：成功记录唯一，重推自动跳过）

## 4. 报工台账纪律

- `work_reports` 只增不改（仅 INSERT）；更正 = 冲减负记录（`sign=-1`，`remark` 必填）
- 完成量口径：`SUM(qty)`（qty 冲减时为负，符号编码在数量内）
- 超量拦截：`schedule.over_report_pct`（默认 100 = 允许超报至 2 倍任务量，可调 0 严格拦截）
- 可入库量 = `SUM(报工合格) − SUM(已入库)`，超量入库 422
