# 虹越智造平台 · 前端（真实后端模式）

> 默认连接 Laravel 后端，页面数据和写操作均通过 `/api` 接口完成。后端不可用时直接显示接口错误，
> 不会静默切换到 Mock 数据。

## 运行方式

```bash
cd frontend
npm install        # 首次
npm run dev        # 打开 http://localhost:5173
```

- 登录请使用后端数据库中的账号和密码（种子管理员：`admin / 123456`）

## 演示模式开关

| 方式 | 说明 |
|------|------|
| 默认 | 关闭，走真实后端 `/api` |
| `VITE_DEMO_MODE=1 npm run dev` | 显式开启演示模式 |
| 控制台 | `enableDemoMode()` / `disableDemoMode()`（当前浏览器会话） |

真实后端：Laravel `php artisan serve --port=8010`，Vite 已配置 `/api` 代理到 8010。

## 演示可玩点（排产页）

1. 任务池选择任务 → 拖拽/点击放到机台时间轴 → mock 层按产能+班制+换模自动算结束时间并保存（保存即锁定）
2. 放到已占用时段 → 弹出冲突框 → 「强制排入并标记超期」或「以插单方式排入（顺延）」
3. 插单确认弹窗：受影响任务顺延预览 → 确认生效 / 撤销（版本回滚）
4. 「自动排」→ 演示异步求解 → 整版接受
5. 「排产明细」抽屉与甘特条点击联动

演示模式仅用于本地验收，写操作在内存 Mock 库生效；正式使用请保持默认真实后端模式。
