# 排产甘特图优化建议（2026-09-21）

## 评审范围

PC 端排产甘特图：资源/机台行、时间轴、计划条、实际报工段、预计延后、拖动调整和任务筛选。当前页面由 `frontend/src/views/schedule/GanttView.vue` 与 `frontend/src/components/gantt/GanttChart.vue` 组成。

本建议基于当前页面截图、现有实现和生产排产场景整理。当前系统保持“一个面上的排产计划”，不引入版本、回滚或多套排产方案。

## 当前主要问题

1. 计划、实际、冲突、超期、选中状态同时使用粗色块和红边，颜色语义容易混淆。
2. 计划条和实际条上下叠加，条内文字、数量、进度、时间互相挤压；小段实际报工难以阅读。
3. 资源行缺少快速筛选、分组和负荷摘要，任务少时出现较大的空白区域。
4. 时间轴有日期和比例尺，但缺少更明确的班次、非工作时段、当前光标时间和快速过滤入口。

## 优先改进

### P0-1：统一视觉语义

- 计划条统一蓝色，手工排和自动排不再用不同颜色。
- 实际报工统一绿色细轨道；一条报工记录仍只对应一个连续时间段，多条记录之间保留真实空档。
- 红色只表示冲突或超期；选中任务改用蓝色描边；锁定、冻结、模具维修等使用图标或纹理表达。
- 计划条只保留任务号和工序，数量、进度、详细时间放到悬浮卡片或右侧明细。

### P0-2：提高资源和任务密度

- 左侧固定资源区按“车间 → 资源类型 → 机台/产线”分组。
- 资源行显示班制、产能和当天负荷百分比。
- 无任务资源支持折叠；有任务资源保持展开。
- 行高控制在 56–64px，减少大面积空白。

### P0-3：增加甘特筛选和时间操作

- 支持任务号/订单号/产品搜索。
- 支持车间、机台/产线、状态、异常任务筛选。
- 增加“只看异常”“只看未开工”“只看进行中”等快捷筛选。
- 时间轴增加今天、本周、未来 7 天、未来 14 天快捷范围；放大时以鼠标位置为中心。
- 清晰区分白班、夜班和非工作时间，保留当前时间线和悬停时间线。

## 后续 P1

- 增加资源日负荷条和瓶颈提示，优先帮助计划员发现机台/产线空挡与超负荷。
- 增加冲突摘要面板，可按资源、模具、工序类型跳转到冲突位置。
- 任务选中后显示工序链连接关系，帮助判断前后工序的等待和衔接。

## 参考的成熟产品交互

- SAP 计划看板采用左侧对象/资源信息与右侧时间图组合，并支持资源负荷等辅助图表。
- Infor 生产订单甘特图支持按资源类型、工作中心等条件筛选，并将资源置于纵轴、时间置于横轴，配合缩放查看。
- SAP 甘特图设置提供当前时间线、光标线、分隔线和状态栏等独立辅助能力。
