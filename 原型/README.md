## 关键设计决策（2026-08-26 评审确认）

1. **订单链路**：小程序录销售单→推金蝶→金蝶下推生产订单→本平台**轮询 10min** 拉取排产
2. **排产**：手工为主（点击/拖拽、自动算结束时间）+ OR-Tools 智能辅助；插单弹确认、打断/等待双策略、自动顺延
3. **生产入库**：**分批入库**（报工完成即入库，可入库量=完成−已入库）→ 推金蝶生产入库单（字段映射见报工&入库页）
4. **BOM**：PLM 为主，**工程自审后一键直发金蝶（无审批流）**
5. **报工**：按人留痕（代报必选实际作业人）、只增不改、冲减更正、合格/次品口径 → 二期计件工资
6. **模具**：台账含**适用机台 + 模穴数**（寿命=报工数÷模穴数）；排产校验产品-模具-机台匹配
