01项目概述

1.1 项目背景

公司生产端现有系统无法满足日常管理需求，核心矛盾集中在三处：

  • 黑湖小工单（现用 MES）：没有排产功能、排单不落地、现场操作难推进、定制开发无法实现；仅部分功能可借鉴。
  • 金蝶云星空（现用 ERP）：承担物料 / 库存 / 财务核算，公司明确保留不动；但其自带的 PLM、MES 模块经评估二开与适配性差，不推荐使用。
  • 线下断层：BOM 维护在金蝶生产制造模块，模具生命周期、产品工艺档案、报价数据等全部在线下（Excel / 纸质 / 经验），新品报价依赖老师傅经验、无数据沉淀。

1.2 项目目标

自建一套「PLM + MES + AI 模拟报价 + 管理看板」一体化生产管理平台，替代黑湖小工单，实现：

🎯

排产数字化

订单 → 多产品逐项排产；插单自动顺延；智能排产 + 空余产能推荐，从"无排产"走向"自动排产"

📲

任务落地

排产结果直达机台/班组，工人一眼看到"今天干什么"；报工 1-2 步极简完成

🔁

全链闭环

小程序接单（已有）→ 排产 → 报工 → 进度回写小程序 → 小程序发货 → 推金蝶出库

🤖

AI 报价

新品快速估价：规格+数量 → AI 结合材料/模具摊销/工时/毛利目标出建议价与交期

📊

管理可视

订单进度、产能负荷、延期预警、产量效率，老板/管理层一屏掌控

1.4 商业价值

  • 减少延误交付：智能排产 + 延期预警，减少插单混乱与人工排程失误带来的交期延误。
  • 提升接单效率：AI 新品报价分钟级出价，把握询价窗口，避免"估错价亏单 / 估高价丢单"。
  • 替代重复劳动：消灭"班组长登记 → 纸质 → 专人录入"的断链，数据实时进入系统。
  • 消除信息孤岛：PLM / MES / 小程序 / 金蝶四方打通，业务员不再靠电话问进度。
  • 知识资产化：模具寿命、工艺工时、报价成交数据全部沉淀，越用越准。

4.2 功能优先级总览

首期（P0+P1）聚焦打通「接单 → 排产 → 报工 → 进度回写 → 发货出库」主链路，PLM 为链路提供数据底座，看板与管理机制保障推行。P2 作为二期持续增强：

  • P2 候选：计件工资核算（基于报工数据核算工人工资，报工需满足稽核要求）、机台自动数据采集（注塑机计数器对接）、多基地扩展、报价模型深度学习化（基于历史成交数据训练）、供应链物料预测。

07功能规格（模块级详细设计）

7.1 PLM 产品数据模块

7.1.1 产品档案

  • 字段：产品编码（对齐金蝶物料编码）、名称、规格、单位、状态（开发/试产/量产/停产）、默认模具、默认工艺路线。
  • 规则：产品编码与金蝶物料编码保持一致（以金蝶为主做映射，避免双主数据冲突）；状态流转有记录。

7.1.2 BOM 管理（PLM 为主，发布推金蝶）

  • 层级结构：成品 → 半成品/原材料（含材料配方），带用量、单位、损耗率。
  • 版本管理：每次修改生成新版本，工程自审后一键发布（一期无审批流），发布动作同步推送金蝶生产制造模块。
  • 存量数据：迁移期从金蝶 BOM 一次性导入，后续以 PLM 为主维护。
  • 权限：工程/工艺维护 → 自审后直接发布（操作留痕兜底）。未发布版本不可被排产/报价引用。

7.1.3 工艺路线

  • 工序序列：成型（注塑/吹塑）→ 喷漆 → 效果 → 包装；每道工序绑定：可用机台类型或班组、标准产能（件/小时）、班制、换模时间（成型工序）。
  • 支撑排产引擎（自动算结束时间）与 AI 报价的工时计算。
  • 配置便捷性（重点设计）：
    • 标准工序模板：喷漆/效果/包装等常用工序做成模板，一键选用，不必每次新建；
    • 类似产品复制：相似产品可直接复制已有工艺路线再改参数，杜绝重复录入；
    • 批量维护：机台标准产能、班制、换模时间为"机台侧默认值"，产品侧为空时自动取默认；支持 Excel 批量导入机台产能与工艺参数；
    • 即时预览：配置过程中即时显示"按此产能，1000 件该工序需 X 小时"的换算提示，减少配置错误。

7.2 排产模块（一期：手工排产为主 · 智能排产为辅）

7.2.0 排产策略（外部调研结论 + 分阶段落地）

  • 外部调研结论：注塑排产在学术界对应「带序依赖换模时间的并行机调度（P‖sds）」，即多台同型注塑机 + 模具切换耗时与前后产品相关；标准目标 = 最小化完工周期 + 最小化总拖期。工程上有Google OR-Tools CP-SAT（开源免费）等求解器可直接求解，100 任务规模毫秒~秒级；配套 job_shop_lib 封装与甘特图组件成熟。
  • 一期策略：手工排产为日常主操作路径（便捷性铁保底，必须好用）；智能排产作为"一键自动排/重排"辅助按钮，计划员可整版接受、局部采纳或回滚。即使智能算法效果不达预期，手工排产也能支撑全部业务。
  • 二期深化：积累真实参数（产能/换模时长）后，逐步提高智能排产采纳率；可引入序依赖换模矩阵 + 元启发式（改进 GA）。

7.2.1 输入

  • 生产任务：订单 → 产品 → 数量 → 交期（来自小程序订单/手工/Excel）。
  • 资源：机台（类型、2 班制日历、标准产能）、班组（人工线工时）、模具（每产品可用模具、换模时间）。
  • 约束：已锁定任务、已排产占用、模具状态（保养/维修期间不可用）。

7.2.2 智能排产算法（外部借鉴 · P0 辅助）

  1. 排序规则：任务按交期紧迫度 + 客户优先级排序（EDD 规则）。
  2. 建模求解：采用 OR-Tools CP-SAT 建模——每任务=机台可选的区间变量，机台内 AddNoOverlap，目标最小化总完工时间 + 加权总拖期（可按"紧交期"调节）；求解器输出排程。
  3. 换模优化：同类产品/同色系连续排产，减少换模次数（序依赖换模最小化）；换模时间计入机台占用。
  4. 空余产能推荐：插单时自动定位最早可用机台空档；生产空闲期推荐可提前生产的产品。
  5. 插单顺延：插入后原产线后续任务自动往后顺延，输出"受影响订单交期变化清单"。

7.2.3 手工排产交互（一期核心 · 便捷性重点设计）

  • 机台空缺一目了然：甘特图按机台分行，空闲时段灰块清晰展示；左侧"待排任务池"列出未排任务（含数量/交期/重量级标识）。
  • 拖拽排产：从任务池拖任务到机台时间轴，自动吸附到最近空闲时段；可连续拖动多个任务。
  • 自动计算结束时间（用户核心诉求）：任务拖上机台后，系统按 机台标准产能 + 班制（2班）+ 换模时间 自动计算开始/结束时间并即时显示，计划员无需手算。
  • 冲突即时报错：位置产能不足 / 模具不可用 / 超客户交期，即时红框提示 + 可选"强制排入（标记超期）"。
  • 交期自动对照：排产结果自动对照订单交期，晚于交期自动标红并提示顺延方案。
  • 一键智能 / 重排：点击"自动排/重排"调用智能算法生成建议排程，可整版接受或局部采纳；支持回滚到上一版本。
  • 插单操作：拖入紧急任务 → 系统自动顺延原产线后续任务并给出受影响的订单清单，一键确认或回滚。
  • 保存即锁定：计划员确认后排程锁定，报工按锁定排程执行；锁定后变更需解锁留痕。

7.3 任务派工与落地（P0）

  • 排产结果自动生成生产任务单：机台/班组、产品、数量、起止时间、模具、标准工时。
  • 今日任务视图（手机端）：工人/班组长登录即见本机台/班组当天任务 —— 解决"任务不落地"。
  • 任务状态机：待开始 → 进行中 → 暂停（异常）→ 已完成；报工驱动状态流转。

7.4 现场极简报工（P0）

  • 报工方式：扫任务二维码 → 任务详情 → 点选"完成 N 件 / 累计完成"，1-2 步完成；支持补报（班组长当日批量登记）。
  • 登录与免密（已确认）：工人用自带手机登录，方案＝微信扫码登录（PC 端）/ 小程序微信授权（移动端，openid 绑定工号后免密）/ 企业微信身份免登（企微已部署，优先推荐）；首次绑定后日常使用零密码。
  • 防重复：服务端校验累计报工数不超过任务量（可配置超 100% 提示）。
  • 联动：报工即更新任务进度 → 看板/小程序/模具开模次数/产量报表同步。
  • 工资核算预留（二期）：报工记录为二期计件工资核算的数据源——一期即按"谁报工/何时报/哪台机/哪个任务/实际作业人"完整留痕（代报必选实际作业归属人），保证可稽核；二期基于报工流水 × 计件单价自动算薪。
  • 冲减与质量口径：台账只增不改，报错用「冲减」（负数量）更正留痕；报工区分合格数/次品数，计件按合格数。
  • 离线容错：弱网环境允许本地暂存，联网自动补传。

7.7 AI 模拟报价（P0）

7.7.1 输入

  • 产品规格（尺寸/重量/壁厚等）、预估数量、客户、是否含模具费、目标毛利率。
  • 可选的相近老品参照（AI 学习历史报价/成交数据）。

7.7.2 计算模型（第一版：规则引擎 + LLM 辅助，二期：历史数据训练）

# 建议价构成（规则引擎） 建议单价 = (材料成本 + 加工成本 + 模具摊销 + 损耗) × (1 + 目标毛利率) 材料成本 = Σ(材料用量 × 材料单价) ← 来自 BOM/报价数据底座 加工成本 = Σ(工序标准工时 × 工序费率) ← 来自工艺路线（机台费率/人工费率） 模具摊销 = 模具造价 ÷ 预估订单总数(或寿命上限) ← 来自模具台账 损耗 = 材料成本 × 行业损耗率 ← 来自报价参数配置 # LLM 辅助层 - 解析客户规格描述 → 结构化参数（用料判断/近似品匹配） - 解释报价构成、生成报价说明话术 - 校验异常价（偏离历史成交价 ±30% 时提示）

7.7.3 输出

  • 建议价（含成本明细，可展开）、建议交期（联动排产：按当前产能估生产周期+排队缓冲）、报价说明。
  • 业务员可调价 → 生成正式报价单（报价单可推小程序给客户）。
  • 数据沉淀：每条询价/报价/是否成交/成交价留档，构成后续训练数据集。

7.8 发货管理（小程序增强 · 一期不打通金蝶出库）

  • 业务员在小程序选择订单/产品/已生产数量发起发货；支持分批发货（订单可拆多次）。
  • 可拍照、填收货信息/物流单号；出库数量不超过已生产数量校验。
  • 发货完成记录发货状态（待发/部分发/已发完）并同步小程序与看板；不推送金蝶销售出库单（见 6.5 衔接说明）。
  • 分批入库（已确认）：报工完成即可分批入库（不必等全部完工），可入库量 = 报工完成量 − 已入库量；每次入库独立生成生产入库单推金蝶（成品入库、库存增加）；发货前校验金蝶库存余量防超发。

集成风险提示：金蝶 K3Cloud 接口需确认授权方案与账套权限；建议一期先实现"推销售订单 + 推销售出库单 + 物料/BOM 同步"三个核心接口，其余逐步扩展。

11测试方案

11.1 测试层级

  • 单元测试：排产引擎（排序/分派/换模/插单顺延）、报价计算（成本构成/毛利）、报工防重校验等核心逻辑。
  • 接口测试：与小程序、金蝶的集成接口契约测试（含失败重试、幂等）。
  • 场景测试：重点业务流（录单→排产→报工→发货→出库）、异常流（插单顺延、减产、模具故障）。
  • 验收测试：按 4.1 验收标准逐项，车间真实环境试运行 2 周。

13运营与推行方案

13.1 推行策略（对应"管理没强制推进"痛点）

  • 工程/工艺：PLM BOM/工艺/模具维护 + 发布流程。
  • 业务员：进度查询 + 移动发货 + AI 报价（小程序端操作说明）。
